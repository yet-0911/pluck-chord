# 彈撥和弦指法

幫國樂彈撥樂器檢查「寫出來的和弦到底按不按得到」的網頁工具。可以自由修改定弦，找出和弦的可行按法。也能匯入 MuseScore 樂譜，逐拍檢查整個聲部。

**線上使用：** https://yet-0911.github.io/pluck-chord/

手機、iPad、電腦的瀏覽器都能直接打開，不需要安裝，也不需要登入任何帳號。
在 iPhone／iPad 的 Safari 按「分享 → 加入主畫面」，就可以像 app 一樣從主畫面打開。

---

## 適用樂器

內建定弦（由低到高）：

| 樂器 | 定弦 |
|---|---|
| 中阮 | G2 D3 G3 D4 |
| 大阮 | D2 A2 D3 A3 |
| 柳琴 | G3 D4 G4 D5 |
| 琵琶 | A2 D3 E3 A3 |

每條弦的音高都可以自己改，也可以增減弦數（2～6 條），任何有品的彈撥樂器都能用。
弦的編號依國樂習慣：最高音的弦是一弦。

> 揚琴是用琴竹擊弦，沒有按品的問題，不適用這個工具的判斷。

## 功能

### 1. 和弦找按法
選和弦的根音（簡譜）和種類（大三、小三、七和弦、掛留和弦等），列出目前定弦下所有按得到的按法，從好按排到難按。

- 可以設定「最低音必須是根音」
- 四音和弦可以選擇省略五音
- 點任一種按法，會在指板上顯示並彈出聲音

### 2. 指定音高檢查
把譜上寫的音（含高低八度）輸入進去，app 會試遍所有「哪個音放哪條弦」的分配方式，告訴你按得到或按不到。按不到時會說明原因。

輸入方式有兩種：
- 點畫面上的簡譜按鍵
- 直接打字，例如 `G4 Bb4 Eb5` 或 `3 5 1'`

### 3. 和弦進行
一行打一個和弦，一次檢查整段進行。

- 逐個判斷按不按得到
- 考慮前後和弦，挑出**換把最少**的一串按法
- 換把距離太大會標出來
- 「從頭彈一次」可以聽整段

### 4. 匯入樂譜（MusicXML）
匯入 MuseScore 匯出的樂譜，逐小節、逐拍檢查整個聲部：

- **按不按得到**：按不到時會說明原因，並建議怎麼改（例如某個音移八度、省略重複的音名）
- **單音旋律的把位**：整段一起考慮，挑出換把最少的走法
- **掃弦或分解**：同時撥的音在相鄰弦上可以掃弦，中間隔弦會標「需分解」
- **換把速度**：依照譜上的速度計算，時間太短又要換把時會提醒
- **持續音**：延音中的音如果必須換弦，會提醒
- **整段播放**：照樂譜節奏播放，指板會跟著顯示目前的按法
- 可以勾選「只顯示有問題的地方」

上次匯入的樂譜會記在你的瀏覽器裡，重新打開頁面不用再選一次。

### 5. 自由按
直接在指板上點手指位置，app 會判斷按不按得到，並辨認是什麼和弦。

## 「按得到」的判斷規則

以下規則都可以在上方的「手指限制」裡調整：

| 項目 | 預設值 | 說明 |
|---|---|---|
| 上下最大跨度 | 5 個半音 | 同一個把位中，最低品到最高品的距離 |
| 每多隔一條弦，跨度減少 | 1 個半音 | 手指橫向張開越遠，能拉開的品差越小。預設下相鄰弦可差 5、隔一條弦可差 4、一弦到四弦可差 3 |
| 可用手指數 | 4 | 左手按弦的手指數 |
| 至少要響幾條弦 | 3 | 用於「和弦找按法」 |
| 指板範圍 | 15 個半音 | 從空弦往上算 |
| 允許食指橫按 | 開 | 最低品同品多弦算一根手指 |
| 允許跳過中間的弦 | 關 | 關閉時，同時撥的弦必須相鄰 |

這些規則是依一般演奏經驗的簡化模型。如果發現判斷跟實際手感不合，請依自己的狀況調整。

## 輸入格式

### 音名（五線譜）
- 寫法：音名＋八度數字，中央 C 是 `C4`
- 升記號用 `#`，降記號用 `b`
- 例：`G4 Bb4 Eb5`、`C#4 E4 A4`

### 簡譜
- 以目前選的調為準（例如 1 = ♭E）
- `'` 是高八度，`,` 是低八度，可以重複使用（`1''`、`5,,`）
- 升降記號寫在數字前面：`#4`、`b7`
- 例：`3 5 1'`

### 和弦進行
- 一行一個和弦，也可以用 `|` 隔開
- `//` 開頭的行是註解，不會被檢查

上方的「音符顯示」可以切換畫面上用簡譜或音名顯示。

## 從 MuseScore 匯出樂譜

1. MuseScore 選「檔案 → 匯出」
2. 格式選 **MusicXML**（`.mxl` 壓縮或 `.musicxml` 都可以）
3. 在 app 的「匯入樂譜」分頁按「選擇樂譜檔」

小技巧：
- 在 MuseScore 的樂器面板把樂器名稱設成 **柳琴、琵琶、中阮、大阮**（或縮寫 L.Q.、P.P.、Z.Z.），匯入後會自動套用對應的定弦。認不出的聲部名稱（例如 Piano）要在「用什麼樂器檢查」手動選。
- 匯出整份總譜，就能在「檢查哪個聲部」切換不同樂器。
- 如果分譜是比實音高或低八度記譜，要調整「記譜與實音」，不然很多音會被判成超出音域。

### 目前的限制
- 速度只讀樂譜開頭的速度標記，中途變速不會跟著變（可以手動改速度欄位）
- 反覆記號不會展開，照樂譜順序從頭看到尾
- 裝飾音不列入檢查
- 在降號調裡，升記號的音可能會用同音異名顯示（例如 C♯ 顯示成 D♭），不影響判斷

## 技術說明

- 整個 app 就是一個 `index.html`，沒有後端伺服器
- 讀取 `.mxl` 壓縮檔時會從 cdnjs 載入 [JSZip](https://stuk.github.io/jszip/)
- 聲音由瀏覽器的 Web Audio 即時合成
- 設定和上次匯入的樂譜存在瀏覽器的 localStorage，只留在自己的裝置上，不會上傳

### 更新方式
把新的 `index.html` 上傳到這個儲存庫、覆蓋舊檔，GitHub Pages 通常一兩分鐘內就會更新。如果打開還是舊版，請強制重新整理（電腦按 Ctrl＋Shift＋R，Mac 按 Cmd＋Shift＋R）。
